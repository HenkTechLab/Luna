## Installer

The same installer is used for every language:

```sh
sh install_luna.sh
```

The installer supports a language argument for its messages:

```sh
sh install_luna.sh nl
sh install_luna.sh en
sh install_luna.sh de
sh install_luna.sh fr
sh install_luna.sh es
sh install_luna.sh it
sh install_luna.sh pt
```

Luna configuration itself already contains separate language modules under `packages/languages/`.
